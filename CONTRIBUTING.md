# Feedback and maintenance

Rajiv Yanamandra is the sole code contributor and maintainer.

You are welcome to open issues for reproducible bugs, feature requests, documentation problems, and questions. Search existing issues first and include the version, a minimal input, expected behavior, and actual behavior when relevant. Remove credentials, personal data, and proprietary source before posting; issues are public.

External code contributions and pull requests are not accepted. Pull request creation is restricted to repository collaborators. This policy governs contributions here; it does not restrict MIT rights to use, fork, modify, or redistribute the public software.

Interested in Harness? Use the Harness enquiry form for a non-confidential introduction.
